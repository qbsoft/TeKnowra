# 化工与成品油行情采集

通过浏览器读取有证据的报价。知识库提供来源与口径，实时网页提供价格，CRM 工具负责业务写入。技能本身不提供浏览器或写入接口。

## 执行顺序

1. 检查当前可用工具。浏览器不可用则报告阻塞；CRM 写入工具不可用则只生成待入库清单。定时执行也必须有真实浏览器会话，不能用 HTTP 请求替代。
2. 从关联知识库“化工与成品油行情采集”（ID：`1c745324-4de7-4a83-95c1-dcd9aa206a8e`）读取《行情来源与浏览器采集规范》。使用当前提供的知识库搜索及文档分块读取工具；未关联或读取失败时报告阻塞，不声称已读。隆众需登录时读取《隆众试用账号与站点访问说明（内部）》，凭据仅用于对应官方网站，绝不输出到报告、CRM、其他站点或技能文件。取不到凭据时可继续生意社公开行情，并单列隆众未完成原因。
3. 浏览器访问隆众 https://www.oilchem.net/ 、成品油入口 https://oil.oilchem.net/oil/refinedoil.shtml 及免费补充来源生意社 https://www.100ppi.com/ 。通过可见导航查找产品报价，读取原文。不得调用外部网站数据接口、隐藏接口或以搜索摘要代替证据。验证码、会员到期或权限不足交由人工处理，不绕过。
4. 默认关注92号汽油、95号汽油、0号柴油；原油另作参考。用户未指定地区或企业时，保留页面披露的地区和主体，不假定。记录原文价格与范围，不自行取中间值。
5. 按下面字段表整理并校验，分别输出已核实行情、待复核、未获取与原因、CRM写入结果。

## 行情字段

| 字段 | 要求 |
|---|---|
| 产品、规格、质量标准 | 保留原文，CRM 产品必须唯一匹配，ID 全程为字符串 |
| 报价主体、地区、价格类型 | 企业报价、市场均价、期货、零售限价分开 |
| 价格/区间、币种、单位 | 不混用人民币/吨、人民币/桶、美元/桶；期货保留合约月份 |
| 税费、交付口径 | 原文未披露记未知，不默认含税或出厂 |
| 报价日期、发布时间、采集时间 | 三者分开；北京时间判断今日，旧价标实际日期 |
| 原文链接、证据 | 提供可追溯 URL 和支撑数字的原文，证据不含登录凭据 |

仅对规格、日期、地区、币种、单位与交付口径一致的记录做跨来源比较。冲突保留双方并待复核，不平均、不覆盖。节假日无新报价不生成今日记录。

## CRM 写入条件

配套MCP工具为 `find_price_products(query)`、`list_competitor_prices(product_id, competitor_name)`、`record_competitor_price(quote)`。只有运行时实际列出这些工具才可调用，不能因技能提到名字就认为已经接入。产品查询需priceStd_view，竞品查询需priceCompetitor_view，新增需priceCompetitor_add。

写入仅支持CNY单值现货报价，`tax_included`必须是已核实布尔值；`quote_date`为报价日期，`collected_at`为北京时间采集日期，`collected_time`为带时区采集时间，`published_time`为可选带时区原文发布时间。原文未披露时间则不填。来源URL、规格、证据及时间保存在CRM备注中，总长最多500字符，超长需缩短证据而非截断URL。接口尚无服务端原子幂等保障，必须串行操作，不启动并发自动写入任务。

实际报价企业、CRM产品、价格、币种、单位及报价日期齐全才可进入写入检查。市场指数、均价、国际原油期货不能伪装为竞品企业报价。若接口不能表达未知税费、区间或原币种，则暂不写入。

只调用当前列出的 CRM 工具，遵循工具参数与当前用户权限。写入前按来源、报价日期、产品规格、主体、地区及价格口径查重。无查重能力时暂缓写入。工具超时先查结果，不盲目重试，报告“写入状态未知”而非0条或成功。只有工具明确成功才能报告已入库，并保留返回的记录标识；成功但无ID时说明缺少ID并补查，不虚构。没有工具且没有发起写入时输出“待入库，实际写入0条”。

## 判例

昨日山东92号汽油市场均价只能列为昨日参考行情；今日炼厂柴油缺税费时先待核实；SC 与 Brent 分币种、分合约列为原油参考。以上均不能直接充当今日汽柴油竞品报价。
