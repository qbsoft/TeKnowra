# 合同审查 · 定标与判例

配合 `SKILL.md` 使用。这里全部是实测中真实判错过的情形，不是假想例子。

---

## 一、严重度定标示例

⚠️ **审查时不要用这张表去覆盖清单的 `severityDefault`。** 清单已定级的一律回填，
见 SKILL.md 第一节。这张表有两个用途：

1. 给 `severityDefault` 留空的风险点定级；
2. 给**编写清单的人**做定标参考——下面 8 条在现行清单里预设为「一般」，
   按口径应为「重大」，属于清单待校准项。

下面每条按 SKILL.md 的六条口径应为**重大**。

| 条款约定 | 应判 | 为什么 |
|---|---|---|
| 验收合格并开票后 **180 日**付款 | 重大 | 现金流实质受损。近半年占用全部货款，资金成本与坏账敞口都由我方承担 |
| **不设预付款** | 重大 | 现金流实质受损。全部生产投入由我方垫资，对方违约时我方已投入无法收回 |
| 验收不合格，对方**有权拒付全部价款并要求返还已收款** | 重大 | 现金流 + 对方单方权利。局部瑕疵可导致全额款项归零 |
| 对方**有权解除合同、拒收、退货退款** | 重大 | 对方单方权利。我方无对等解除权，履约完全系于对方意愿 |
| 逾期交付按合同总价**每日 1%** 计违约金 | 重大 | 违约金畸高。折年化 365%，远超司法保护水平 |
| 赔偿范围含**可得利益、停产停工、对外违约赔偿**，且**不设上限** | 重大 | 金额敞口无上限。单次违约的赔偿可数倍于合同额 |
| 争议「可提起诉讼，**或**提交仲裁」 | 重大 | 条款可能无效。约定不明，实务中常被认定仲裁条款无效，救济路径落空 |
| 全文**无我方开户行与银行账号** | 重大 | 履行要件缺失。对方可据此拖延付款，且我方主张付款时缺少约定依据 |

判「一般」的对照：

| 条款约定 | 应判 | 为什么不是重大 |
|---|---|---|
| 质量标准只写「符合国家现行标准」，无标准号 | 一般 | 争议时需另行举证，但不直接造成金额敞口，可通过补充协议明确 |
| 运输、装卸费用由我方承担 | 一般 | 成本明确、可测算，报价时可覆盖 |
| 保密义务只约束我方 | 一般 | 义务不对等，但实际损失取决于是否真的发生泄密 |
| 管辖法院约定在对方所在地 | 一般 | 增加诉讼成本与不便，不影响实体权利 |

> 注意最后两组的对比：「保密义务单方」和「对方可单方解除」都是不对等，
> 但前者只在特定事件发生时才有损失，后者是**对方随时可用**的权利。
> 区分点在于**对方能否单方面、无条件地行使**。

## 二、引用的正反例

原文：

```
6.4 乙方有权基于验收结果解除本合同、拒收设备或要求退货退款。因退货、换货产生的
运输、装卸、仓储等一切费用，一律由甲方负担。
...
10.4 甲方违约的，乙方有权单方解除本合同并要求甲方赔偿。
```

| 写法 | 结果 |
|---|---|
| `乙方有权基于验收结果解除本合同、拒收设备或要求退货退款。` | ✅ 定位成功 |
| `6.4 乙方有权基于验收结果解除本合同...\n10.4 甲方违约的，乙方有权单方解除本合同...` | ❌ **两处拼接，原文中无此连续片段** |
| `乙方有权解除合同并拒收设备` | ❌ 复述，改了字 |
| `乙方有权基于验收结果解除本合同` | ✅ 截取一段也可以，只要连续 |

要同时指出 6.4 和 10.4 时：引用后果更重的那一处，另一处写进 analysis：
「第 10.4 条另行赋予对方在我方违约时的单方解除权，与本条叠加。」

## 三、立场翻转对照

同一条款，立场不同，判定相反。开批次前务必确认「我方是谁」。

| 条款 | 站卖方 | 站买方 |
|---|---|---|
| 付款时点在验收后 180 日 | hit（收款过迟） | pass，甚至有利 |
| 风险自签收时转移 | hit（签收前风险在卖方，尤其卖方承运时） | pass |
| 定制成果知识产权归买方 | hit（丧失核心权利） | pass |
| 卖方逾期按日 1% 计违约金 | hit（违约金畸高） | pass |
| 管辖法院在买方所在地 | hit | pass |

立场选错的表现是：大量本该 hit 的判成 pass，而报告读起来仍然「像那么回事」。
所以**不要从合同内容去猜立场**，要用户明确告诉你，或从 CRM 的合同台账里读。

## 四、缺失型 analysis 的写法

反例（无法验证）：

> 合同中未约定收款账户信息。

正例：

> 全文检索「开户行」「银行账号」「账户名称」「收款账户」「汇入行」，均无匹配。
> 合同仅在 2.4 约定「付款方式为银行转账」，未给出我方账户。付款时需另行提供，
> 对方可据此主张付款条件不具备而拖延。

差别在于：正例让用户能自己复核这个「没有」。
