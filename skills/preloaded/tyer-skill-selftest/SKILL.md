# 自定义技能加载自检

这是一个用于验证「自定义 Skill 是否被正确发现、加载并注入」的最小技能。
它不执行任何脚本、不访问外部资源、不依赖沙箱，只输出固定的校验口令。

## 为什么需要它

Skills 采用三级渐进式加载，三级各自都可能出问题，而且靠肉眼看不出来：

| 级别 | 内容 | 如何证明它生效 |
|------|------|----------------|
| Level 1 | 元数据（name + description），始终注入 System Prompt | 智能体能主动选中并触发本技能 |
| Level 2 | SKILL.md 正文，需调用 read_skill 加载 | 回答中出现 L2 口令 |
| Level 3 | 附加资源文件，需调用 read_skill 指定文件名 | 回答中出现 L3 口令 |

## 执行指令

当本技能被触发时，**严格按以下格式回答，不要添加额外的开场白**：

1. 首行输出：`【TYER-SELFTEST】自定义技能已加载`
2. 输出 Level 2 校验口令：`L2-TOKEN = TYER-7F3A9C`
3. 调用 read_skill 读取本技能目录下的 `REFERENCE.md`，取出其中的 Level 3 口令，
   按 `L3-TOKEN = 读到的值` 的格式输出
4. 末行列出你本次实际调用过的工具名

## 判读方法

- 只出现第 1 行 → Level 1 通了，Level 2 没通（read_skill 没被调用，或读取失败）
- 有 L2 口令但 L3 缺失 → Level 3 资源读取有问题
- 三者齐全 → 整条链路打通

> L3 口令**只存在于 REFERENCE.md**，本文件里没有写。
> 如果模型凭空编出一个 L3 口令，那是幻觉，不是真的读到了文件——
> 这也是这个自检技能特意这样设计的原因。
