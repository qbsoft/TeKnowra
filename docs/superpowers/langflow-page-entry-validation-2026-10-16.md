# Langflow 页面新建和发布验收

2026-10-16。本机开发增量，保留已有未提交修改、历史会话、旧静态绑定和封存 M/N。没有提交、推送、部署或上线。研发创建 Langflow 智能体无须再逐个修改后台绑定文件。

## 页面操作

1. 在 TeKnowra「智能体」点击「创建智能体」，执行引擎选择「Langflow 可视编排」。填写名称、提示词和模型。Langflow 使用智能推理，关闭长期记忆与网络搜索；知识库必须明确指定或不使用。
2. 沿用原表单选择授权知识库、MCP 服务及具体工具、运行沙箱及已安装技能。合同场景开启「Langflow 会话文本附件」会同时禁止会话问答自动入库。历史索引不修改。
3. 点击创建后保留编辑窗口，出现「Langflow 流程接入」。选择「创建通用流程」，生成已连接的聊天输入、Agent、聊天输出、平台模型以及所选知识库、MCP、技能节点。模型供应商密钥不进入画布。
4. 也可选择「关联已有流程的独立副本」。来源只列当前空间、当前用户有编辑权限且已登记的编辑流程；创建新副本，保留原图。统一 Langflow 服务身份不能证明任意外部流程的空间归属，因此不接受直接填任意 Flow ID 或冻结运行图。
5. 「打开编排」进入 Langflow。新建时将主页面提示词初始化为 Agent Instructions；后续以画布中发布的指令为准。模型参数、节点连接及专家组织在画布中修改。目录连接沿用既有 15 分钟只读目录机制。
6. 修改平台资源后保存并「同步并校验资源配置」。这个操作更新授权绑定并检查现有图，不会自动新增或删除画布节点；需要新增节点时在画布编排，或生成新的通用草稿。移除资源而图仍引用它会拒绝同步。发布托管草稿前自动保存并再同步校验。
7. 填写发布名称，点击「发布当前草稿」冻结版本并激活。「在聊天中试运行」仅在已有激活版本时启用。选旧版本并「激活所选版本」可回退，运行中的任务保持启动版本。

计算脚本的可选高级设置仍是 JSON 数组：固定技能名、相对入口及受限输入 schema。它用于研发审核可信脚本，未新增任意 shell，也不声称不可信代码的 OS 隔离。附件、制度、技能及固定脚本继续复用上一轮能力。

## 权限和持久化

新端点仍使用 OwnedAgentOrAdmin；服务重新检查真人登录、当前账号有效性、活跃空间成员、Contributor 以上角色、智能体所有者或管理员。关联列表和复制后保存均重新校验权限。资源来自数据库中已保存的 Agent，不接受请求传入的空间、模型授权、节点能力或密钥。信用查询继续要求访问复核工具及原 crm-credit guard。

托管草稿增加在既有 release store 的 `drafts` 中，原子写入，重启恢复，不修改旧发布工件及激活指针。运行优先读取激活的冻结版本。旧静态绑定继续兼容，新建 Langflow Agent 没有绑定或未发布时禁止回退原生引擎。无需数据库迁移或历史回填。

该存储沿用当前单进程文件模式，不支持多个后端实例同时写同一个版本文件。

服务仍需管理员一次性配置 Langflow 编辑和运行身份、组件模板与版本元数据存储。后续逐智能体操作均通过页面完成。备份需同时保留 TeKnowra 数据库、Langflow 数据库、发布元数据和相关技能镜像等既有依赖；源码归档还须包含新增 `integrations/langflow/templates/agent-components.json`。
